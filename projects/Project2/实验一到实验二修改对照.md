## 功能变化与主要文件

| 模块 | 实验一 | 最终实验二 | 主要文件 |
|---|---|---|---|
| 执行模型 | 输入任务名，调用单个任务，返回加载器 | 启动所选多个任务，通过PCB和调度器轮流运行 | `init/main.c`、`kernel/sched/sched.c` |
| 启动与镜像 | BIOS读取内核，传递任务数和信息偏移 | 保留协议；启动栈与pid0一致，镜像工具检查段布局及大小边界 | `bootblock.S`、`head.S`、`tools/createimage.c` |
| 任务加载 | 按名称查任务，逐扇区读取 | 延续按名加载，统一声明和边界；加载后执行fence.i | `kernel/loader/loader.c`、`include/os/task.h`、`include/os/loader.h` |
| 用户启动 | 清BSS、运行main，返回原调用者 | 清BSS、使用独立栈；main意外返回后循环yield，不返回原交互加载器 | `arch/riscv/crt0/crt0.S` |
| Task 1 | 没有多任务切换实现 | 初始化PCB/栈，FIFO就绪队列，保存恢复ra/sp/s0-s11 | `include/os/list.h`、`include/os/sched.h`、`init/main.c`、`arch/riscv/kernel/entry.S` |
| Task 2 | 没有互斥锁及阻塞队列 | 同key复用锁；竞争失败阻塞；释放时FIFO移交所有权 | `kernel/locking/lock.c`、`kernel/sched/sched.c`、`include/os/lock.h` |
| Task 3 | 主要通过跳转表直接调用服务 | U态ecall进入内核，保存异常现场，分发系统调用并sret返回；支持睡眠 | `entry.S`、`trap.S`、`kernel/irq/irq.c`、`kernel/syscall/syscall.c`、`tiny_libc/syscall.c`、`kernel/sched/time.c` |
| Task 4 | 没有定时抢占 | STIE时钟中断、重设定时器、轮转调度和唤醒；pid0处理空队列 | `init/main.c`、`kernel/irq/irq.c`、`kernel/sched/sched.c` |
| 构建 | Project 1及预实验目标 | LAB_STAGE=1..4分阶段构建，TASKS选择任务，默认A-Core任务组合 | `Makefile`、`include/os/config.h` |
| 辅助验证 | 实验一测试 | 保留原实验二测试，另增主动yield、锁竞争、寄存器和抢占探针 | `test/validation/`、`tools/host_qemu_smoke.py`、`tools/test_image.py` |

## 建议阅读顺序

1. `init/main.c`：从“加载后直接调用”变成“初始化PCB并调度”。
2. `include/os/sched.h`、`include/os/list.h`：看PCB字段、状态及队列操作。
3. `kernel/sched/sched.c`、`arch/riscv/kernel/entry.S`：看进程选择、switch_to及上下文切换。
4. `kernel/locking/lock.c`：看阻塞、唤醒和锁所有权移交。
5. `tiny_libc/syscall.c`、`kernel/syscall/syscall.c`、`trap.S`、`kernel/irq/irq.c`：串起ecall到sret。
6. `kernel/sched/time.c`及定时器处理函数：区分无时钟中断的睡眠检查和时钟抢占。
