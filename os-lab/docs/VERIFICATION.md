# 本次实现的核验记录

验证日期：2026-10-28。以下结果来自本次开发机器和新建的 Debian 容器，不代表已经在用户新建的 GitHub Codespace、学校 QEMU、Pynq 或 DASIC 环境复验。

## 实际通过

- 构建当前 `.devcontainer/Dockerfile`。在本机受管理代理环境中，测试构建临时注入了该环境提供的 CA 信任；证书没有写入仓库，TLS 和发行版包签名验证保留。
- 新容器以 `vscode` 普通用户执行配置中的完整 `postCreateCommand`：工具检查、练习版实际启动、宠物店规则检查、课程 A-Core 解压/构建和10项镜像检查。
- 工具链为 RISC-V GCC 14.2、binutils 2.44、QEMU 10.0.13；内核显式使用 GNU C11。
- 练习版 `make boot-check`：QEMU 中实际进入内核，接收 info/help/quit 并正常退出。
- 参考版 `make check MODE=reference`：六关行为检查和所有命令行演示通过。包括实际寄存器切换、U→S→U ecall、错误用户地址、错误调用号、硬件定时器、多线程抢占重叠证据与睡眠。
- GDB 连接暂停中的 QEMU，在 `kernel_main` 命中断点并读取栈指针。
- 宠物店 7 组 Node 规则测试通过，覆盖六关正确/错误代码、数组状态变化、奖励、领养、饲料、存档规范化。
- Chromium 实际操作页面：错误答案无奖励、无限循环超时、六关通关、逐只领养与喂食、刷新保持进度、导出/导入存档、无效导入保持原状态、390px 手机无水平溢出，以及加载后断网继续执行练习。
- 原有 OS Quest 的规则回归测试通过；Pages 工作流保留原游戏首页，新游戏加入 pet-kernel 子目录。
