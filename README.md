## 在浏览器运行 A-Core

已提供 GitHub Codespaces 环境，自动安装 RISC-V 编译器、QEMU 并解压构建项目。

1. 点击仓库页面的 **Code → Codespaces → Create codespace on main**，等待环境创建和初始化完成。
2. 在底部终端输入 `python3 scripts/acore.py run`，实时观察内核任务的运行输出。
3. 退出模拟器：按 **Ctrl+A**，松开后再按 **X**。
