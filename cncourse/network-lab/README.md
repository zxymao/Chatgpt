# NET / FIELD · 计网交互实验室

基于 [`计算机网络期中复习大纲.md`](../复习资料/计算机网络期中复习大纲.md)，提取 337 张术语/别名卡，覆盖正文第一至四章及原提纲明确标出的补充框架。人工通读术语清单与大写缩写审计共同记录在 [术语清单.md](术语清单.md)。组合概念共享解释及关联实验，337 是术语/别名卡片数，不是 337 套协议实现。

## 打开与使用

直接用现代浏览器打开 **[index.html](index.html)**，无需安装依赖或联网。所有 CSS、脚本、术语及原提纲文本已内嵌。若浏览器限制直接打开本地文件，可从仓库根目录运行：

```sh
python3 -m http.server 8000
```

打开 `/cncourse/network-lab/index.html`。搜索缩写、中文或英文全称 → 选择术语 → 改变参数并应用 → 单步或自动演示。拖动 3D 拓扑旋转，滚轮或按钮缩放，键盘方向键也可操作。点击“原始提纲”阅读内嵌原文，点击术语出处定位到源文件行。术语清单可下载为 Markdown，实验配置和轨迹可导出 JSON。当前实验和参数尽力保存在本机 localStorage；禁用存储仍可使用。

|生成树|修改根桥优先级、断链、重算根端口与冗余阻塞链路|

|IP 分片|MTU、首部长、DF、丢片、偏移和 MF、重组结果|

## 范围与精度

- 这是本地教学模拟器，不运行真实协议栈，不扫描网络、捕获流量或连接公网服务。
- 3D 使用实际 XYZ 几何与透视投影，动画光点代表离散事件，不按真实传播速度或包字节比例绘制。流水时隙与传播延迟分开解释。
- 分发时间为理想流体下界；香农、奈奎斯特及 ALOHA 公式有各自理想假设。CDMA 假设同步、等幅、正交。CSMA/CA 是教学事件过程，不是完整 802.11 定时仿真。
- ARQ 展示一个发送窗口及一次故障；GBN/SR 序号空间限制实际校验，不模拟无限历史帧或全部计时器。ACK 按课件表示“最后连续收到的帧”。
- STP 使用三桥等代价的课件简化模型，不实现完整 BPDU 定时和收敛状态机。OSPF/Dijkstra 与 RIP 计算真实对应路径/距离；BGP 只示范路径防环与策略含义，不冒充完整 BGP 决策实现。
- NAT/VPN/IGMP 与路由协议保留“补充”标签；组织史、标准、单位、介质等不伪装成独立可运行协议，通过概念卡与相关实验理解。
- TCP/UDP 只涉及原提纲中的层次、字段及封装，不补造第五章专门内容。IP 与端口示例使用私网或文档示例地址。

## 维护和验证

无构建依赖，Python 3 + Node.js 22 或更高版本即可：

```sh
python3 cncourse/network-lab/build.py
node cncourse/network-lab/engine.test.cjs
```

源码是 `terms.tsv`、`engine.js`、`app.js`、`template.html`；构建产物为 `index.html`、`terms.json`、`术语清单.md`。源文 SHA-256、每条精确行号与片段随产物保存，可检查提纲更新。

浏览器测试使用开发环境已提供的 Playwright 与 Chromium，不是网站运行依赖：

```sh
# 先从仓库根启动上面的静态服务
node cncourse/network-lab/browser-test.cjs
```

22 项算法/来源测试及真实浏览器检查覆盖 16 个实验切换、错误输入、参数修改、搜索、原文、自动播放、下载、相机旋转、刷新续用和 390px 手机布局。截图默认保存到 `/tmp/net-field-{desktop,mobile}.png`。测试不修改用户数据；浏览器使用独立测试上下文。

当前云端 Chromium 管理策略禁止 `file://` 导航，直接文件打开检查记为跳过；另以阻断全部外部请求后注入完整独立 HTML，验证离线渲染与 CRC 操作。HTTP 页面交互正常；没有修改受管浏览器策略。
