来源文件名、实际页数及 SHA-256 见 [sources.json](sources.json)。引用页码按文件中从 1 开始的实际页序。原课件的旧版子网计数规则与现代 CIDR 口径、ARP 长度单位、分片对齐及滑动窗口 RTT 算法在正文就地辨析。

重新生成需要 Python 3、Pandoc、XeLaTeX、ctex，以及 Noto CJK 和 DejaVu 字体：
