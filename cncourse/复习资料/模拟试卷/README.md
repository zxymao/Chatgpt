# 计网期中模拟试卷 A

范围：现有《计算机网络期中复习大纲》第一至四章；目录补充只作基础辨析，不展开第五章传输层专门机制。建议用时 **120 分钟**，总分 **100 分**。题目数据与复习提纲示例不同。

- [试卷 PDF](计网期中模拟卷A-试卷.pdf)：6 页 A4，不含答案，有答题区域；空间不足可另附纸。
- [参考答案 PDF](计网期中模拟卷A-参考答案.pdf)：6 页 A4，包含计算过程、评分细则和复盘入口。
- [试卷 HTML](计网期中模拟卷A-试卷.html) / [答案 HTML](计网期中模拟卷A-参考答案.html)：独立离线文件，浏览器打印时使用 A4。
- [可编辑试卷](计网期中模拟卷A-试卷.md) / [可编辑答案](计网期中模拟卷A-参考答案.md)。

## 题型与分值

|题型|题号|分值|
|---|---|---:|
|单项选择|1–10|20|
|填空（每空 1 分）|11–15|10|
|简答|16–19|20|
|计算与过程|20–25|50|
|合计|25 题|100|

计算与过程题覆盖流水线时延、比特填充与 CRC、ARQ 窗口、交换机 FDB、IPv4 分片、VLSM 与最长前缀匹配。简答还涉及 P2P、跨网 IP/MAC 变化、CSMA/CA 和 STP。题目不是按提纲每个名词逐一穷举，分值仅用于这份自测卷。

`exam.json` 是结构化题目、答案和评分数据，记录每题对应的提纲节号、精确行号及源文件 SHA-256。`build_exam.py` 使用 Python 标准库生成独立 HTML、Markdown 和元数据；`print_exam.cjs` 使用开发环境的 Playwright 与 Chromium 输出 PDF，并检查每页内容和页脚是否重叠。

```sh
python3 cncourse/复习资料/模拟试卷/build_exam.py
node cncourse/复习资料/模拟试卷/print_exam.cjs
```

已验证：25 个连续题号、分值合计与分步评分一致、主要计算结果、PDF 各 6 页且为 A4、每页不溢出、不遮挡页脚，试卷和答案分离。参考答案页采用独立排版，不与试卷夹页混排。
