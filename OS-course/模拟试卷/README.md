## 范围

覆盖根目录中 10 份原始课件，共 378 页：

1. Intro01 课程简介：操作系统的抽象、资源管理与隔离。
2. Intro02 操作系统结构与组成：用户态／内核态、系统调用、宏内核与微内核。
3. Proc01 进程：程序与进程、ELF、PCB、进程状态转换。
4. Proc02 线程 (1)：线程共享资源与独立上下文、用户级／内核级线程及映射。
5. Proc03 CPU调度：SRTCF、RR、时间片、优先级反转与继承。
6. Sync01 临界区与锁：竞态、原子指令、关中断与跨核互斥。
7. Sync01 临界区与锁-扩展：读写锁、写者饥饿、RCU。
8. Sync02 死锁：死锁条件、安全状态、银行家算法。
9. Sync03 信号量-条件变量-屏障：P/V、有界缓冲区、Mesa 管程、屏障。
10. Sync04 进程间通信：管道、共享内存、套接字及同步需求。

未将课程简介列出的后续内存管理、设备管理和文件系统完整章节纳入专项考题；当前目录尚无这些章节的独立课件。复习资料目录中的二次整理 PDF 不作为新增命题范围；原有课程文件和其他项目未修改。

## 可追溯性与校验

- 课件版本：`main` 的 `296b64a3c1e9aa312a778de6d957e7a5b9786fb1`，已与 GitHub 远端核对。
- [sources.json](sources.json) 保存各课件文件名、页数、SHA-256 和来源提交。
- [exam.json](exam.json) 保存每题的题干、答案、分值和课件页码；页码均按 PDF 文件页序从 1 开始计数。
- 第 27 题用独立离散时间模拟复算调度，校验甘特图、完成时刻及平均周转／等待时间。
- 第 29 题枚举全部 24 种进程顺序，核验安全序列和试分配不安全结论。
- PDF 已检查页数、A4 尺寸、正文／页脚边界、文本提取、中文显示及版式。

## 修改与重建

先编辑 `exam.json`，再在仓库根目录执行：

```bash
python3 OS-course/模拟试卷/build_exam.py
node OS-course/模拟试卷/render_pdf.cjs
python3 OS-course/模拟试卷/validate_exam.py
```

HTML／Markdown 生成只使用 Python 标准库；PDF 渲染使用当前云环境已有的 Playwright、Chromium 和 Noto 中文字体。验证脚本使用当前环境已有的 PyMuPDF。
